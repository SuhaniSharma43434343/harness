# Scroll Video Engine

A reusable APP-02 section, `ScrollVideo`, that turns a continuous video into a pinned, scroll-controlled story. A new project supplies a video, a scene config and layout settings; the component does not change.

Quick start for a project that already selected APP-02:

```sh
forge approach <project> APP-02
forge scroll-video new <project> story --beats 5 --layout cinematic
forge scroll-video prompts <project> story            # run these in your video generator
forge scroll-video add-video <project> story --video ./story.webm --licence "Generated by the client in <tool>; client owns the output"
forge scroll-video stills <project> story             # check the markers by eye
forge scroll-video check <project> story
```

Then place `- use: "APP-02/ScrollVideo"` with `config: "story"` in a page and build.
